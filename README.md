# 数元链

**公共数据授权运营的数据元件确权、计量与自动分账系统**

> 数据被加工转手 N 次之后，权属归谁、用了几次、钱怎么分、被谁偷偷转卖——数元链把这四个问题写成了可执行的合约。

---

## 这是什么

一套面向"公共数据授权运营"场景的联盟链系统。它不重做隐私计算，也不重做数据交易所，只做**授权之后的规则执行层**：

| 机制 | 解决的问题 | 实测效果 |
|---|---|---|
| 元件血缘登记 | 一份数据派生 N 手后，权属与来源如何界定 | 内容哈希 + 字段模式哈希 + 血缘 DAG，可追溯任意祖先 |
| 授权策略状态机 | 用途、次数、有效期无法强制 | 七类越权场景拦截率 **100%** |
| 整数守恒分账 | 收入如何自动回流到源头 | 1000 次调用分账误差 **0 微元** |
| 鲁棒指纹溯源 | 数据被转卖后如何归因 | 六种变换检出率 **100%**，误报 **0/200** |
| 同态聚合 + 差分隐私 | 多机构联合统计不泄露个体 | 密文求和误差 **0**，ε=1.0 时误差 0.39% |

判断标准只有一条：**换成"数据库 + 合同"也能做的，一律不上链。**

## 快速开始

```bash
# 依赖（Python 3.11+）
python -m pip install flask numpy matplotlib reportlab pypdf

# 1. 启动演示台
python main.py serve
#    浏览器打开 http://127.0.0.1:8000，点「一键跑完六幕」

# 2. 或者直接在终端看完整流程
python main.py demo

# 3. 复现全部指标（约 30 秒）
python main.py bench

# 4. 校验账本完整性与重放一致性
python main.py verify

# 5. 功能测试（32 条用例，含 16 条异常路径）
python bench/functional_tests.py

# 6. 重新生成两份 PDF 报告（需要 Chrome 或 Edge）
python main.py report
```

无需 Docker、无需外网、无需数据库。核心链、合约、Paillier、指纹算法全部自带，仅依赖标准库。

## 六幕演示

| 幕 | 动作 | 现场能看到什么 |
|---|---|---|
| ① | 登记 3 个数据元件 | DAG 出现 3 节点 2 边，内容哈希与字段模式哈希上链 |
| ② | 银行申请授权 | 用途/次数/有效期写进合约；非持有者签发被当场拒绝 |
| ③ | 调用 3 次 | 扣次进度条 + 三方余额实时变化（60% / 24% / 16%） |
| ④ | 转售样本溯源 | 相似度 100%、链上立案、授权批量冻结、再调用被拒 |
| ⑤ | 四道闸门 | 用途不符 / 次数耗尽 / 身份冒用 / 绕过结算，四条红色拒绝 |
| ⑥ | 同态聚合 | 三段密文 → 解密总和 → 加噪均值 → 结果哈希上链锚定 |

演示台为单页原生 JS，无需构建，所有数字来自真实交易与真实区块。

## 架构

```
应用层    元件登记台 · 授权签发 · 用数审计 · 泄漏取证 · 隐私统计
服务层    REST API · 事件索引器 · 指纹检测器 · 同态聚合器
合约层    DataElementRegistry · AccessPolicy · Settlement · TraceAndFreeze · AggregateAnchor
共识层    4 验证节点 · 3/4 门限签名 · 状态根 · 全量重放 · Merkle 证明
数据层    链上状态 KV · 区块日志（只追加） · 链下数据（不出域）
```

双执行后端：**内置联盟链引擎**（默认，Python，零依赖，用于复现与测试）与 **FISCO BCOS + Solidity**（`contracts/solidity/`，五份合约已通过 solc 0.8.19 编译校验）。

- PDF 元数据已清空作者字段。
